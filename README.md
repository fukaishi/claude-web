# Generate GIF Animation

ブラウザ上で完結する画像編集・GIFアニメーション生成ツール

## 特徴

- **完全クライアントサイド**: すべての処理がブラウザ内で完結、サーバー不要
- **画像編集機能**: 回転、拡大縮小、クリッピング
- **ドラッグ&ドロップ**: 直感的なフレーム順序設定
- **プレビュー機能**: 生成前にアニメーションを確認
- **カスタムタイミング**: フレームごとに表示時間を設定可能

## 機能

### 1. 画像アップロード
- 対応形式: JPEG, PNG, GIF, WebP
- ドラッグ&ドロップ対応
- 自動的に512×512pxにクリッピング

### 2. 画像編集
- **回転**: 90度単位で回転
- **拡大縮小**: 50%～300%
- **クリッピング**: 正方形の切り抜き

### 3. アニメーション設定
- ドラッグ&ドロップでフレーム順序を変更
- フレームごとに表示時間を設定（10ms～10,000ms）
- リアルタイムプレビュー

### 4. GIF生成
- 高品質なGIFアニメーション生成
- 進捗表示
- ワンクリックでダウンロード

## セットアップ

### 前提条件
- Node.js 18以上

### インストール

```bash
npm install
```

### 開発サーバー起動

```bash
npm run dev
```

ブラウザで `http://localhost:5173` にアクセス

### ビルド

```bash
npm run build
```

ビルド成果物は `dist/` ディレクトリに出力されます。

## 技術スタック

- **React 18**: UIフレームワーク
- **Vite**: ビルドツール
- **Tailwind CSS**: スタイリング
- **gif.js**: GIFエンコーディング
- **@hello-pangea/dnd**: ドラッグ&ドロップ機能

## 使い方

1. **画像をアップロード**: STEP 1でファイルを選択またはドラッグ&ドロップ
2. **画像を編集**: STEP 2で回転、拡大縮小、クリッピングを適用
3. **画像を保存**: 編集後、「保存」ボタンをクリック
4. **フレームを追加**: STEP 3の保存済み画像からフレームを選択
5. **順序を調整**: STEP 4でフレームをドラッグして順序を変更
6. **タイミング設定**: 各フレームの表示時間を調整
7. **プレビュー**: 再生ボタンでアニメーションを確認
8. **GIF生成**: 「GIF生成・ダウンロード」ボタンでGIFをダウンロード

## 制限事項

- 最大画像サイズ: 10MB
- 最大フレーム数: 100フレーム
- 最大保存画像数: 50枚
- 出力サイズ: 512×512px固定

## ブラウザ対応

- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

## プライバシー

このアプリケーションはすべての処理をブラウザ内で行います：
- サーバーへの画像送信なし
- データの外部保存なし
- 個人情報の収集なし
