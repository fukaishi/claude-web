# Generate GIF Animation

ブラウザ上で完結する画像編集・GIFアニメーション生成ツール

## 特徴

- **完全クライアントサイド**: すべての処理がブラウザ内で完結、サーバー不要
- **画像編集機能**: 回転、拡大縮小、クリッピング
- **ドラッグ&ドロップ**: 直感的なフレーム順序設定
- **プレビュー機能**: 生成前にアニメーションを確認
- **カスタムタイミング**: フレームごとに表示時間を設定可能

## 機能

### 1. 画像アップロード
- 対応形式: JPEG, PNG, GIF, WebP
- ドラッグ&ドロップ対応
- 自動的に512×512pxにクリッピング

### 2. 画像編集
- **回転**: 90度単位で回転
- **拡大縮小**: 50%～300%
- **レイヤー編集（クリッピング機能）**:
  - 画像の一部を選択して編集し、元画像に合成
  - 選択範囲を360度自由回転
  - 選択範囲を拡大縮小（10%～300%）
  - **アスペクト比固定/解除**: 縦横を連動または個別に調整
  - **横方向のみ拡大縮小**: アスペクト比解除時に横だけ変更可能
  - **縦方向のみ拡大縮小**: アスペクト比解除時に縦だけ変更可能
  - 選択範囲を移動（±256px）
  - 繰り返し適用可能（例: 目を編集 → 口を編集 → 鼻を編集）

### 3. アニメーション設定
- ドラッグ&ドロップでフレーム順序を変更
- フレームごとに表示時間を設定（10ms～10,000ms）
- リアルタイムプレビュー

### 4. GIF生成
- 高品質なGIFアニメーション生成
- 進捗表示
- ワンクリックでダウンロード

## 使い方

### 基本的な流れ
1. **画像をアップロード**: STEP 1でファイルを選択またはドラッグ&ドロップ
2. **画像を編集**: STEP 2で回転、拡大縮小、クリッピングを適用
3. **画像を保存**: 編集後、「保存」ボタンをクリック
4. **フレームを追加**: STEP 3の保存済み画像からフレームを選択
5. **順序を調整**: STEP 4でフレームをドラッグして順序を変更
6. **タイミング設定**: 各フレームの表示時間を調整
7. **プレビュー**: 再生ボタンでアニメーションを確認
8. **GIF生成**: 「GIF生成・ダウンロード」ボタンでGIFをダウンロード

### レイヤー編集機能（クリッピング）の使い方

この機能を使うと、画像の一部分だけを編集して元画像に合成できます。
例: 顔写真で目だけを拡大・回転させたい場合など

**操作手順:**
1. 「クリッピングモード ON」ボタンをクリック
2. キャンバス上をドラッグして編集したい範囲を選択（矩形選択、最大512×512px）
3. 「範囲を確定して編集モードへ」ボタンをクリック
4. **編集モードに入ります**（背景に元画像が表示されます）
   - **回転スライダー**: -180° ～ +180°で自由に回転
   - **🔒/🔓 アスペクト比固定/解除ボタン**: 縦横の拡大縮小を連動させるか個別調整するかを切り替え
   - **横拡大縮小スライダー**: 10% ～ 300%で横方向に拡大縮小
   - **縦拡大縮小スライダー**: 10% ～ 300%で縦方向に拡大縮小
   - **横移動スライダー**: -256px ～ +256pxで左右に移動
   - **縦移動スライダー**: -256px ～ +256pxで上下に移動
5. 「編集を完了」ボタンをクリック
6. 元画像に編集後の範囲が合成されます
7. **繰り返し可能**: 再度クリッピングモードで別の箇所を編集できます

**使用例:**
- 顔写真で目だけを大きくする（アスペクト比固定で拡大）
- 横長に見せたい場合は横方向だけ拡大（アスペクト比解除）
- 縦長に見せたい場合は縦方向だけ拡大（アスペクト比解除）
- 傾いた文字を回転して修正
- 特定の要素だけを移動・拡大

## 制限事項

- 最大画像サイズ: 10MB
- 最大フレーム数: 100フレーム
- 最大保存画像数: 50枚
- 出力サイズ: 512×512px固定

- データの外部保存なし
- 個人情報の収集なし
